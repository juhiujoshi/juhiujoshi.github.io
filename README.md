# Juhi Joshi — AI Engineer Portfolio (Engineering Case Studies Edition)

A static, responsive GitHub Pages-ready portfolio with **9** project case studies.

## Preview

Unzip and open `index.html` in a browser. If file-based browser restrictions interfere, run `python3 -m http.server 8000` from the website folder and open `http://localhost:8000`.

## Included

- A homepage with project cards, experience, leadership, awards, and contact information.
- Nine detailed project pages containing original conceptual SVG architecture illustrations, implementation breakdowns, design decisions, and evidence/limitations.
- The exact original one-page PDF résumé uploaded by Juhi; it was not modified.
- The corrected LinkedIn link. No GitHub profile or profile photo is assumed.

## Privacy and sharing

The technical summaries omit confidential configuration, proprietary diagrams, partner identities, internal metrics, private datasets, and unreleased code. The employer and résumé remain identifiable. Review all content and employer disclosure obligations before publishing.

## Publish

Upload everything in this folder (including `assets` and `projects`) to the root of a GitHub Pages repository. Enable Pages in repository Settings → Pages → Deploy from branch.
